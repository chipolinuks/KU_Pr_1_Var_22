# Эмулятор оболочки ОС

## Общее описание
Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом.
Поддерживает виртуальную файловую систему (VFS) и набор команд.

## Функции и настройки
- Парсинг команд с поддержкой аргументов в кавычках
- Команды: ls, cd, exit
- Заголовок окна содержит имя VFS

## Сборка и запуск
```bash
# Запуск через bat-файл
.\run.bat

# Или напрямую
python -m src.main
