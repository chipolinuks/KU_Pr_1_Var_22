# Эмулятор командной строки UNIX-подобной ОС

## Общая информация
- **Дисциплина:** Конфигурационное управление
- **Вариант:** 22
- **Язык реализации:** Python 3
- **Интерфейс:** Графический (GUI на базе tkinter)

## Описание этапов реализации

### Этап 1. REPL и графический интерфейс
Реализован минимальный прототип с графическим интерфейсом. Окно содержит область вывода (стилизована под терминал) и поле ввода. Реализован парсер ввода с корректной обработкой аргументов в кавычках с помощью модуля `shlex`. Добавлены команды-заглушки `ls`, `cd` и команда завершения `exit`.

### Этап 2. Конфигурация и стартовые скрипты
Добавлена поддержка аргументов командной строки (`--vfs`, `--script`) через модуль `argparse`. Реализован механизм выполнения стартовых скриптов: команды читаются построчно, ошибочные строки пропускаются без прерывания всего скрипта, ввод и вывод имитируют диалог с пользователем. При запуске выводится отладочная информация о переданных параметрах.

### Этап 3. Виртуальная файловая система (VFS)
Подключена VFS на основе JSON-файла. Все операции выполняются строго в памяти. Реализована поддержка двоичных данных через кодировку base64. Добавлена обработка ошибок загрузки (файл не найден, неверный формат JSON) с выводом соответствующего сообщения без аварийного завершения программы.

### Этап 4. Основные команды
Реализована полноценная логика навигации и чтения файлов:
- `ls`: вывод отсортированного списка содержимого директории с поддержкой относительных и абсолютных путей
- `cd`: смена текущей директории с разрешением путей
- `head`: вывод первых 10 строк файла
- `tac`: вывод содержимого файла в обратном порядке строк
- `rev`: вывод содержимого файла с обратным порядком символов в каждой строке

## Описание функций модулей

### Модуль src/vfs.py
- `__init__`: инициализирует корневую директорию и текущий путь
- `resolve_path`: преобразует относительный или абсолютный путь в канонический абсолютный путь
- `load_from_json`: читает и парсит JSON-файл в структуру данных VFS
- `get_node`: возвращает словарь узла по заданному пути
- `list_directory`: возвращает список имен дочерних элементов директории
- `get_file_content`: декодирует и возвращает содержимое файла (с поддержкой base64)

### Модуль src/shell.py
- `__init__`: инициализирует VFS и регистрирует доступные команды в словаре
- `parse_command`: разделяет строку ввода на команду и аргументы с учетом кавычек
- `execute`: диспетчеризирует выполнение команды по словарю зарегистрированных обработчиков
- `cmd_ls`: реализует логику листинга директории
- `cmd_cd`: реализует логику смены директории
- `cmd_head`: реализует вывод начала файла
- `cmd_tac`: реализует вывод файла в обратном порядке строк
- `cmd_rev`: реализует реверс символов в строках файла
- `cmd_exit`: устанавливает флаг завершения работы оболочки
- `is_running`: возвращает текущий статус работы оболочки
- `run_script`: читает файл скрипта и последовательно выполняет команды, игнорируя ошибки

### Модуль src/gui.py
- `__init__`: создает окно tkinter, инициализирует Shell и выводит отладочную информацию
- `_create_widgets`: формирует элементы интерфейса (текстовое поле, скроллбар, поле ввода)
- `_on_enter`: обрабатывает ввод пользователя, передает данные в Shell и обновляет экран
- `_append_output`: безопасно добавляет текст в поле вывода, сохраняя его доступным только для чтения
- `_run_startup_script`: выполняет переданный скрипт и выводит результаты в GUI
- `run`: запускает главный цикл обработки событий tkinter

## Сборка и запуск

### Требования
- Python 3.8+
- Установленный pytest для запуска тестов

### Запуск эмулятора
```bash
# Базовый запуск
python -m src.main

# Запуск с загрузкой VFS и стартовым скриптом
python -m src.main --vfs data/vfs_deep_structure.json --script config/commands_stage4.txt
